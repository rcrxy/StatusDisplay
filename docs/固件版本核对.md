## 设备与官方发布

当前设备的 USB 标识为 `VID_3434&PID_0660&REV_0110`；与 Launcher 显示的 Q6 PRO Knob V1.1.0 一致。

从官方 Launcher 的公开脚本读取实际 API 定义，再按其 VID/PID 编号算法计算 `65536 * 0x3434 + 0x0660 = 875824736`。

- [官方产品接口](https://launcher.keychron.com/vapi/v2/product/875824736)：产品为 `Q6 PRO Knob`，最新固件 `1.1.0`。
- [官方固件列表接口](https://launcher.keychron.com/vapi/v2/firmware/875824736)：返回 `1.1.0` 和 `1.0.2`，`languageDesc` 均为空；没有可用的更新说明。
- [官方 V1.1.0 二进制](https://cdn.shopify.com/s/files/1/0059/0630/1017/files/q6_pro_ansi_encoder_via_v1.1.0_2510101212.bin?v=1764123062)：76,640 字节，SHA256 `6E37BBE6A3F3E6589E8FCF9A980CD1FA39C27EA35E0AEF0D566E44CA14E6BF81`。

二进制中读取到构建时间 `2025-10-10-12:12:09`。接口的记录更新时间是 `2026-07-10T03:14:33.000Z`，与固件构建时间是不同字段。没有找到可以确认对应源码提交的构建标识。

公开接口响应和下载的二进制保存在 `.firmware-stage/`，不执行这些文件。

## 已执行的迁移

新工作树：`D:/Workspace/StatusDisplay/.firmware-stage/qmk-wls_2025q1`。

分支：`hostled/wls-2025q1`，通过原固件仓库的 Git worktree 创建。原仓库保留在 `D:/Workspace/KeyboardFirmware`。

custom 路径：`keyboards/keychron/q6_pro/ansi_encoder/keymaps/custom`。

- 按键和旋钮映射重新采用新基础的原始 VIA keymap，包括上游的 `UG_*` 灯效键码。
- Host LED 协议和接入层迁移到新基础，继续使用 VIA custom-value `0xAC` 通道。
- LED 定义文件从 `info.json` 改为 `keyboard.json`；108 个 LED 的矩阵坐标及排列顺序核对一致。
- 新基础已经移除 `common.mk` 中无条件引入动态消抖的代码；旧方案的公共构建修复没有移入新分支。
- 上游更新了 SNLED27351 接口、RGB 休眠配置、驱动负载统计和旋钮中断接口；使用完整新分支，避免只替换板型目录造成跨版本接口混用。
- ChibiOS 与 ChibiOS-Contrib 使用新分支 gitlink 指定提交；精确版本记录在 `firmware-dependencies.json`。

端到端测试支持显式指定板型定义路径，默认使用新分支的 `keyboard.json`。模拟只替换硬件接口，不能验证官方 V1.1.0 的未公开差异。
