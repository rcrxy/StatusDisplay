# Host LED Protocol V1 — 状态与格式边界

状态：LED 项格式已定义；命令级字节布局尚未冻结，当前程序不发送 HID。

每个 LED 项为 6 字节：row:u8, column:u8, flags:u8, r:u8, g:u8, b:u8。
flags bit 0 表示覆盖，其他位必须为零。RGB 均为 0..255；黑色覆盖有效。
完整快照省略解除覆盖项，并按 row/column 排序。固件仍须支持 flags=0 的合法项。
HID 报告长度为 32 字节；主机库额外需要的 Report ID 不计入这 32 字节。

命令 GET_INFO/BEGIN/DATA/COMMIT/STATUS 必须包含可关联的回复。
冻结前必须定义：命令空间、会话/事务编号宽度、Snapshot Version、包序号和数量、项数、字节序、回复状态、能力位和超时。
不能在头部宽度未确定时承诺每包容纳 4 项；测试应使用两端共用的固定报文向量。
重复包同内容幂等，异内容拒绝；禁止同快照重复坐标；整批校验成功后在 RGB 帧边界提交。
其余行为遵循开发方案.md。离线预览的二进制输出仅是 LED 项序列，不是可直接发送的完整 HID 报告。
